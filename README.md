# 🌐 WebEssentials

## 📌 About
WebEssentials is a collection of basic web development projects created as part of an internship task at **CampusValley**.  
This repository includes beginner-friendly projects to demonstrate fundamental **HTML, CSS, and JavaScript** concepts.

## 📂 Projects Included
- 🔢 **Calculator** - A simple calculator built using HTML, CSS, and JavaScript.  
- 🏠 **Landing Page** - A basic landing page design with responsive UI.  
- 👨‍💻 **Portfolio Website** - A personal portfolio website showcasing skills and projects.  

## 🔧 Technologies Used
- **HTML**
- **CSS** 
- **JavaScript** 

## 🚀 How to Run
1. Clone the repository:
git clone https://github.com/Gunjalsakshi/WebEssentials.git

2. Open the desired `.html` file in a browser.  
3. Explore the projects! 🎉
